## 🚀 التثبيت والإعداد

### **المتطلبات:**
- ✅ متصفح حديث (Chrome, Firefox, Safari, Edge)
- ✅ حساب Google (للـ Apps Script و Sheets)
- ✅ Gemini API Key (اختياري للوضع الذكي)

### **خطوات الإعداد:**

#### **1. نشر التطبيق:**

**خيار A: GitHub Pages (موصى به)**
```bash
# Clone the repository
git clone <repository-url>
cd zoho-sales-intelligence

# Push to GitHub
git add .
git commit -m "Initial commit"
git push origin main

# Enable GitHub Pages in repository settings
# Settings → Pages → Source: main branch
```

**خيار B: أي خدمة استضافة ثابتة**
- Netlify
- Vercel
- Firebase Hosting

#### **2. إعداد Google Apps Script (للوضع الذكي):**

1. افتح [Google Apps Script](https://script.google.com/)
2. إنشاء مشروع جديد
3. انسخ كود `google-apps-script/Code.gs`
4. أضف Gemini API Key في المتغير `GEMINI_API_KEY`
5. انشر كـ Web App:
   - Deploy → New Deployment
   - Type: Web App
   - Execute as: Me
   - Who has access: Anyone
6. انسخ رابط Web App

#### **3. إعداد Google Sheets (للتسجيل):**

1. إنشاء Google Sheet جديد
2. انسخ Sheet ID من الرابط
3. أضفه في `Code.gs` في المتغير `SHEET_ID`
4. سيتم إنشاء الجداول تلقائياً عند أول استخدام

#### **4. ربط Frontend بـ Backend:**

في ملف `ai-chat.html`، غيّر:
```javascript
const USE_REAL_API = true;
const GEMINI_API_URL = 'YOUR_APPS_SCRIPT_WEB_APP_URL';
```

## 🐛 استكشاف الأخطاء

### **المشكلة: الصفحة لا تظهر بشكل صحيح**
**الحل:**
- تأكد من تفعيل JavaScript في المتصفح
- امسح cache المتصفح
- جرّب متصفح آخر

### **المشكلة: AI Chat لا يعمل**
**الحل:**
- تأكد من إعداد Google Apps Script بشكل صحيح
- تحقق من Gemini API Key
- راجع console في Developer Tools

### **المشكلة: PDF لا يُصدَّر**
**الحل:**
- تأكد من السماح بنوافذ pop-up
- استخدم ميزة Print في المتصفح
- تأكد من تثبيت jsPDF بشكل صحيح

### **المشكلة: البيانات لا تُحفظ**
**الحل:**
- تحقق من Google Sheet ID
- تأكد من أذونات Apps Script
- راجع Execution Log في Apps Script
